# AGENTS.md

Project map for AI agents entering this codebase. Lists all agents, prompts, skills, hooks, and instructions with their purpose and location.

## Repository Structure

```
src/                          # Source files (edit here)
├── agents/                   # Agent definitions
├── prompts/                  # Prompt files
├── skills/                   # Skill definitions + references
└── instructions/             # Instruction files
.github/                      # Build output (generated by `node cli.mjs build`)
├── agents/
├── prompts/
├── skills/
├── hooks/                    # Hook definitions (not in src/ — edit directly)
└── instructions/
cli.mjs                       # Build, install, uninstall CLI
config.json                   # Local config (install dir, tool injection)
```

`src/` is the source of truth. `.github/` is generated — don't edit it directly (except `hooks/`).

## Agents

| Agent | File | Description |
|---|---|---|
| `@eng` | [src/agents/eng.agent.md](src/agents/eng.agent.md) | General-purpose engineering agent. Plans, investigates, implements, and tracks work using `.eng/` documentation. Has behavioral rules for autonomy (three-zone model), research discipline (confidence scoring, budgets), and structured progress tracking. |
| `@eng-plan` | [src/agents/eng-plan.agent.md](src/agents/eng-plan.agent.md) | Planning-only agent. Reads the codebase freely but only writes to `.eng/` directories. ## Hooks

| Hook | File | Status | Description |
|---|---|---|---|
| PreCompact | [.github/hooks/hooks.json](.github/hooks/hooks.json) | Experimental | Fires before context compaction. Instructs the agent to flush in-progress state (objective updates, decisions, timeline entries) to `.eng/` before context is lost. |

## Key Conventions

- **`.eng/` is gitignored.** It's local working memory. Use `includeIgnoredFiles: true` or terminal commands when searching `.eng/` content.
- **Objectives are the central hub.** One objective per effort. Findings and retros link back to objectives via `parent:` frontmatter.
- **`src/` is source, `.github/` is build output.** Run `node cli.mjs build` after editing `src/` files.
- **Config-driven tool injection.** `config.json` can inject additional tools into agent frontmatter at build time (wildcard `*` or per-agent).
